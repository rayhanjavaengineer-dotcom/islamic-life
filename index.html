পাঁচ ওয়াক্ত নামাজ

🕌

শহরের নাম ইংরেজিতে লিখে নামাজের সময় দেখুন। সময় গণনার পদ্ধতিভেদে সামান্য পার্থক্য হতে পারে।

নামাজের সময় লোড হচ্ছে…

নামাজের নোটিফিকেশন পছন্দ

যে ওয়াক্তগুলোর জন্য স্মরণ করাতে চাও সেগুলো নির্বাচন করো।

Firebase project configuration না দেওয়া পর্যন্ত ব্যাকগ্রাউন্ড Push চালু হবে না।

গুরুত্বপূর্ণ: Firebase Push-এর জন্য Firebase project, Web App config, VAPID public key এবং নিরাপদ server-side sender/Cloud Function প্রয়োজন। Android/Chrome-এর background notification sound OS নিয়ন্ত্রণ করে; সম্পূর্ণ আজান অডিও ব্যাকগ্রাউন্ডে সব ফোনে নিশ্চিত করা যায় না।

SALAH GUIDE

নামাজের নিয়ত ও রাকাত

🤲
